## 階段 1：看整體（目標：用三句話介紹 LUNA）

**讀**
- 整理 §1（總覽與流程圖）：只讀這一節，先不要管公式。
- 整理 §2.3、§2.4、§2.5：LLM 怎麼逐字生成、為什麼比分類器難分析。
- 整理 §3：三個面向（OOD、對抗、幻覺），每個一句話。

**操作**
- 網頁 01：先看左圖（LLM 怎麼寫字），指出「隱藏狀態」在哪裡；再看右圖與表格，分清楚黑箱評測、探測激活、LUNA 各看什麼。
- 網頁 02：依序點四個階段，每個階段說出「輸入、輸出」。

**要能說出來**
1. LLM 每寫一個字都有一個隱藏狀態（Llama-7b 是 32 × 4096 = 131,072 個數字），一個答案是一條狀態路徑。
2. LUNA 把這些狀態壓成一個小的機率狀態機，再給每個狀態貼上「好不好」的分數。
3. 用這個分數去抓異常輸出：幻覺、分布外輸入、對抗攻擊。

**過關檢查**：不看筆記，能畫出「輸入 → 隱藏狀態 → 抽象狀態 → 語意 → 分數 → 判異常」這條流程。

## 階段 2：狀態抽象與 DTMC（Lab 1、Lab 2）

**讀**
- 整理 §4.1～§4.4（為什麼抽象、PCA、Grid／Cluster、轉移抽象、DTMC 定義）。§4.5 HMM 先略讀，只記得「HMM 是兩層抽象、表現比 DTMC 差」。

**操作 Lab 1**
1. 劃分方法選 Grid，把 `m`（每維格數）從小拉到大：看 `|S̄|` 增加、紅色空洞格出現、SUC 變差。
2. 換成 KMeans：狀態只出現在有資料的地方。
3. 對照右側分數：異常輸入的 COV 應比正常的高。
4. 看下方「Formulas in this lab」的 SUC、COV、SEN 三個按鈕，各讀一次公式和作用。

**操作 Lab 2**
1. 拉「Traces seen」：看 P̂ 收斂、`Mean |P̂−P|` 變小（資料越多模型越準）。
2. 點節點建立路徑，或按「typical」「odd」：看平均轉移機率（也就是 OOD 分數）怎麼變。
3. 拉「Determinism」：看熵量表上的圓點在「穩定界」與「隨機界」之間移動。
4. 看公式區的轉移機率、路徑分數、SDE。

**要能說出來**
- 抽象就是「降維 + 分群」，把高維連續狀態變成少數離散狀態。
- DTMC 的轉移機率就是「數次數再除以總數」。
- Grid 會有空洞狀態（浪費），Cluster 只在有資料處建立狀態。

**過關檢查**：用 Lab 2 示範「為什麼典型路徑分數高、怪異路徑分數低」。

## 階段 3：語意與異常偵測（Lab 3、Lab 4）

**讀**
- 整理 §5（語意綁定，尤其 §5.4 的表：幻覺綁在狀態、OOD 與對抗綁在轉移）。
- 整理 §7.1、§7.2（偵測流程與論文範例：TruthfulQA 的 "denser" 例子，分數 0.04；OOD 的 0.34 對 0.78）。

**操作 Lab 3**
1. 切換範例（HAL／OOD、正常／異常）。
2. 拖門檻：看判定何時從正常變異常、紅框（第一個低於門檻的 token）怎麼移動。
3. 找一個「判錯」的範例，說明為什麼。

**操作 Lab 4**
1. 選 HE-C，依序切「平均／最大／最差」：看兩個直方圖分開或重疊、AUC 變化。
2. 拖門檻：看黃點在 ROC 曲線上移動（每個門檻一個點）。
3. 讀 AUC 公式與 TPR／FPR 公式。

**要能說出來**
- 語意 θ̄ 是「該狀態的平均好壞」，軌跡分數是路徑上 θ̄ 的平均，低於門檻就判異常。
- 優勢：能指出「從哪個 token 開始壞掉」，不只是「這個答案不好」。
- AUC = 隨機抽一個正常、一個異常，正常分數較高的機率；0.5 是擲硬幣。

**過關檢查**：能講清楚「門檻高 → 抓到更多異常，但誤判更多正常」，並指到 ROC 上的位置。

## 階段 4：公式、指標與實驗結果（最重要，老師最常問）

**讀**
- 整理 §6（12 個指標）：先看 §6.3 的速查表，再回頭讀各指標。
- 整理 §10（RQ1～RQ3 與實務指引）、§9（AUC、Pearson、Kendall）。

**操作**
1. 網頁 07：切換兩個分頁（模型層級 6 個、語意層級 6 個）。**較暗、虛線的卡片**是 Lab 裡有即時數字的公式（SUC、COV、SEN、SS、SDE，以及轉移機率、語意分數），先把這幾個講熟。
2. 網頁 08（Lab 5）：x 軸換成不同指標、任務換 OOD-L 和 HE-C，看 Pearson r 的變化。
   - **注意資料是真實的**（標籤 REAL DATA），來自作者公開的結果，不是模擬。
3. 網頁 09：看 10 個任務的 AUC 範圍，右邊卡片是 RQ1～RQ3 與限制。

**每條公式準備一句話（作用）**

| 指標 | 一句話 |
|---|---|
| SUC | 抽象後的狀態數比原本少多少（越小越精簡） |
| COV | 測試時有多少狀態是訓練沒見過的（越小越好） |
| SEN | 輕微擾動後狀態會不會跳掉（越小越穩） |
| SS | 有多少狀態進去就出不來（sink） |
| SDE | 模型是死板還是亂跳，離兩個極端的中點越近越好 |
| PERP | 對訓練分布擬合得多好 |
| PRE | 抽象後語意失真多少（與 AUC 相關最強） |
| ENT、IVT、NVT、NDT、SL | 語意曲線的隨機性、接近目標值的程度、上升下降的趨勢、意外程度 |

**要能說出來**
- 180 種設定從何而來（27 + 81 + 18 + 54），怎麼在沒有異常標註時用指標挑設定。
- PRE 與 AUC 強相關（Pearson 0.81～1.00）；PERP 是最廣用的模型層級指標；DTMC ≥ HMM，前 5 名全是 DTMC。
- **誠實面**：多數設定的平均 AUC 只有 0.55～0.70，最亮眼的 0.90（HumanEval）是 180 種裡最好的一個。

**過關檢查**：隨機指一個指標，5 秒內說出它量什麼、方向是高好還是低好。

## 附錄 A：一分鐘講稿骨架

1. **問題**：LLM 會幻覺、會被對抗攻擊、遇到沒見過的輸入會出錯，但它內部太大（論文說 Llama-7b 每個字的隱藏狀態有 131,072 個數字）看不懂。
2. **方法**：LUNA 把每個字的隱藏狀態壓成少數抽象狀態，建成一個機率狀態機（DTMC），再把「好不好」的分數貼到狀態上。
3. **偵測**：一個答案變成一條狀態路徑，取路徑上分數的平均，低於門檻就判異常，還能指出從哪個 token 開始壞掉。
4. **結果**：在 3 個模型、7 個資料集、180 種設定下，最佳 AUC 到 0.90，但多數設定只有 0.55～0.70，結果對設定很敏感。
5. **限制**：只適用開源（白箱）模型；模型與資料集的範圍有限。

## 附錄 B：可能被問的問題（回答方向）

| 問題 | 回答方向 |
|---|---|
| 為什麼要抽象？ | 隱藏狀態太大（論文說 Llama-7b 為 131,072 維／token；作者程式碼實際取最後一層 4096 維），降維加分群後才能建小而可解釋的模型（Lab 1） |
| Grid 和 Cluster 差在哪？ | Grid 規則但有空洞狀態；Cluster 只在有資料處建立，比較精簡（整理 §4.2） |
| 為什麼用 DTMC 不用 HMM？ | 論文結果 DTMC 多數指標較好、前 5 名全是 DTMC；作者推測 HMM 是兩層抽象造成落後 |
| OOD 和幻覺的語意有什麼不同？ | 幻覺綁在狀態（真實性）；OOD 和對抗綁在轉移（轉移機率）（整理 §5.4） |
| AUC 0.9 代表什麼？ | 隨機抽一正一負，正常分數較高的機率是 90%；但這是最佳設定，不是平均 |
| 哪個指標最有用？ | PRE 與 AUC 相關最強且最一致；PERP 是最廣用的模型層級指標；其他指標跨任務會變號 |
| 你的實作可靠嗎？ | OOD 可以（AUC 0.88）；幻覺中等（0.77），但評分對象和論文不同，只是縮小版示範，不能和論文數字直接比 |
| Lab 為什麼不是論文的模型？ | 論文沒公開逐 token 隱藏狀態，要重跑 7B 模型在筆電上不實際；Lab 1、3、4 用自己的 GPT-2 實跑同一套流程，Lab 5 用的是作者公開的真實結果 |
| 這個方法的缺點？ | 只能用開源白箱模型；只測 3 個模型；結果對設定敏感、需要調參 |
| 跟 SAPLMA、ITI 差在哪？ | LUNA 多面向、可逐 token 線上監控；SAPLMA 是結束後分類；ITI 是推論時介入（整理 §7.3） |
