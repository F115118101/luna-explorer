01

What the LLM hands to LUNA: one vector per tokenLLM 交給 LUNA 什麼：每個 token 一個向量

LUNA never changes the model, it only reads the last layer; three formulas cover the LLM sideLUNA 不改模型，只讀最後一層；LLM 這一側只需要三條式子

Llama-2-7b is a decoder-only, autoregressive model: read the text so far, compute probabilities for the next token, pick one, append it, repeat. Every time a token is generated, the last block leaves one vector ht(32) ∈ ℝ4096. That vector is the only thing LUNA uses.Llama-2-7b 是 decoder-only 的自迴歸模型：讀前文、算出下一個 token 的機率、挑一個接回輸入，再重複。每生成一個 token，最後一個區塊都會留下一個向量 ht(32) ∈ ℝ4096。LUNA 只用這個向量。

02

LUNA takes over: concrete states and tracesLUNA 接手：具體狀態與軌跡 LUNA 1 · extractLUNA 1 · 抽取

For every generated token, take the last layer's 4,096-dimensional vector; a whole answer becomes a list of vectors每生成一個 token，取最後一層的 4,096 維向量；一整句回答就是一串向量

LUNA treats the LLM as a system that jumps between states. The concrete state st is the last block’s output vector when the t-th answer token is generated; the concrete states of one answer, in order, form a trace.LUNA 把 LLM 當成一個在狀態之間跳來跳去的系統。具體狀態（concrete state） st 是生成第 t 個回答 token 時最後一個區塊的輸出向量；一句回答的所有具體狀態依序排好，叫做軌跡（trace）。

The paper counts 32 × 4,096 = 131,072 dimensions per token but does not say how the layers are combined. The authors’ released code uses only the last block (extract_block_idx = 31), i.e. 4,096 dimensions. This page follows the code.論文寫每個 token 的隱藏狀態是 32 × 4,096 = 131,072 維，但沒有說各層怎麼組合。作者釋出的程式碼只用最後一個區塊（extract_block_idx = 31），也就是 4,096 維。這一頁照程式碼走。

03

PCA: 4,096 dimensions down to 3PCA：4,096 維壓到 3 維 LUNA 2 · reduceLUNA 2 · 降維

Find the directions in which the data varies most, and keep only the coordinates along those找出資料變化最大的幾個方向，只保留在這幾個方向上的座標

4,096 dimensions cannot be cut into cells: 5 cells per dimension would give 54096 cells. LUNA first compresses every vector with principal component analysis (PCA): keep only its coordinates along the k directions in which the training data varies most. Our setting keeps k = 3.4,096 維沒辦法直接切格子：每維切 5 格就有 54096 格。LUNA 先用主成分分析（PCA）壓縮每個向量：只保留它在「訓練資料變化最大的 k 個方向」上的座標。我們的設定是 k = 3。

  1. Center: subtract the mean μ of all training tokens.中心化：減掉訓練集所有 token 的平均 μ。
  2. Covariance: C = (1/(N−1)) Σ (h − μ)(h − μ)⊤, a 4,096 × 4,096 matrix.共變異數：C = (1/(N−1)) Σ (h − μ)(h − μ)⊤，一個 4,096 × 4,096 的矩陣。
  3. Eigendecomposition: sort the eigenvectors by eigenvalue (scikit-learn does this through an SVD of the centered data, which gives the same directions).特徵分解：依特徵值由大到小排特徵向量（scikit-learn 實際上是對中心化後的資料做 SVD，得到的方向相同）。
  4. Project: z = Wk⊤(h − μ) keeps k numbers per token. Steps 1–3 use the training set only; test tokens reuse the same μ and Wk.投影：z = Wk⊤(h − μ)，每個 token 只剩 k 個數字。第 1–3 步只用訓練集；測試 token 沿用同一組 μ 和 Wk。

PCA is not just “a rotation”. With k = d it only changes the coordinate system and loses nothing; the reduction comes from throwing away the last d − k coordinates, and the error this causes is exactly the sum of the discarded eigenvalues (formula 04). The textbook 2-D picture is the special case d = 2, k = 1.PCA 不只是「旋轉」。k = d 時它只換了座標系，什麼都沒丟；降維來自丟掉後面 d − k 個座標，造成的誤差剛好等於被丟掉的特徵值總和（公式 04）。課本常畫的二維圖只是 d = 2、k = 1 的特例。

Grid partition: 3 dims × 5 cells = 125 abstract statesGrid 劃分：3 維 × 每維 5 格 = 125 個抽象狀態 LUNA 3 · abstractLUNA 3 · 狀態抽象

Cut the PCA space into boxes; concrete states in the same box are the same abstract state把 PCA 空間切成方格，落在同一格的具體狀態就是同一個抽象狀態

Find each dimension’s minimum and maximum over the training data and split that range into m equal cells. The cell a point falls into along dimension i is ci; the three cell numbers together name one small box, an abstract state s̄. With m = 5 and k = 3 there are 125 boxes, numbered 0–124.在訓練資料上找出每一維的最小值與最大值，把這段範圍均分成 m 格。一個點在第 i 維落在第幾格，就是 ci；三個格號合起來決定一個小方塊，也就是一個抽象狀態 s̄。m = 5、k = 3 時共有 125 個方塊，編號 0–124。

05

DTMC: count how the states jumpDTMC：數一數狀態之間怎麼跳 LUNA 4 · modelLUNA 4 · 建模

Discrete-time Markov chain: P(s̄ → s̄′) = number of such jumps in the training traces / number of jumps leaving s̄離散時間馬可夫鏈：從狀態 s̄ 跳到 s̄′ 的機率 = 訓練軌跡中這種跳躍的次數 / 從 s̄ 出發的總次數

Every training answer is now a list of abstract-state numbers. A DTMC (discrete-time Markov chain) just counts: the number of jumps from s̄ to s̄′, divided by all jumps leaving s̄, is the transition probability P̄(s̄, s̄′). It assumes the next step depends only on the current state (the Markov property), which is only an approximation for a Transformer.每句訓練回答現在都是一串抽象狀態編號。DTMC（離散時間馬可夫鏈）只要數數：從 s̄ 跳到 s̄′ 的次數，除以從 s̄ 出發的所有次數，就是轉移機率 P̄(s̄, s̄′)。它假設下一步只跟目前狀態有關（馬可夫性質），對 Transformer 來說這只是近似。

On TruthfulQA the score uses the semantics of states (unit 06). The transition probabilities are what OOD and adversarial detection score with, and they are also used to assess the abstract model itself (perplexity, stationary-distribution entropy).在 TruthfulQA 上，分數用的是「狀態」的語意（第 06 單元）。轉移機率用在 OOD 和對抗樣本偵測，也用來評估抽象模型本身的品質（困惑度、穩態分布熵）。

06

Semantics binding: how “truthful” is each state語意綁定：每個狀態有多「真實」 LUNA 5 · semanticsLUNA 5 · 語意

θ̄(s̄) = the share of training tokens in this state that came from true answers; an answer's score = the mean θ̄ of the states it visitsθ̄(s̄) = 訓練時經過這個狀態的 token 中，來自真實回答的比例；一句話的分數 = 它走過的狀態的 θ̄ 平均

Every TruthfulQA training answer has a true/false label (the paper uses the fine-tuned GPT-judge). Semantics binding hands that label to the state of every token in the answer: each state keeps two counters, visits by true answers (pos) and by false answers (neg), and its semantics is θ̄ = pos / (pos + neg).TruthfulQA 的每句訓練回答都有真假標籤（論文用微調過的 GPT-judge 判定）。語意綁定把這個標籤分給回答裡每個 token 所在的狀態：每個狀態記兩個計數，被真實回答經過幾次（pos）、被不真實回答經過幾次（neg），語意 θ̄ = pos / (pos + neg)。

To detect, map a new answer to its state sequence, look up each state’s θ̄ and average: that is the answer’s semantic score. Below the threshold τ means hallucination. A state never seen in training gets θ̄ = 0.偵測時，把新回答變成狀態序列，查每個狀態的 θ̄ 再平均，就是這句話的語意分數。分數低於門檻 τ 就判為幻覺。訓練時沒出現過的狀態，θ̄ 記為 0。

The paper’s Fig. 4 reports this example as s̄199 → s̄5 → … → s̄159 → s̄4 with score 0.04, turning abnormal at “denser”. State 199 is above 125, so Fig. 4 used a different configuration; below is our configuration on the toy data.論文圖 4 的這句例句是 s̄199 → s̄5 → … → s̄159 → s̄4，分數 0.04，在「denser」進入異常狀態。編號 199 超過 125，所以圖 4 用的是另一組設定；下面是我們這組設定在玩具資料上的結果。

07

ROC AUC: how good is this detectorROC AUC：這套偵測器好不好 LUNA 6 · evaluateLUNA 6 · 評估

Score every test answer, sweep every threshold, draw the ROC curve; the area under it = the chance a random true answer scores above a random hallucination對所有測試回答算分數，掃過每一個門檻，畫出 ROC 曲線；曲線下面積 = 隨機一個真實回答分數高於隨機一個幻覺回答的機率

One threshold gives one result. Sweep the threshold from 0 to 1 and compute two rates at each: TPR (share of hallucinations caught) and FPR (share of true answers wrongly flagged); joined up they form the ROC curve. The area under it, AUC, does not depend on the threshold: 0.5 is a coin flip, 1.0 is perfect separation.單一門檻只能給一組結果。把門檻從 0 掃到 1，每個門檻算兩個比例：TPR（幻覺被抓到的比例）與 FPR（真實回答被誤判的比例），連起來就是 ROC 曲線。曲線下面積 AUC 不受門檻影響：0.5 等於擲硬幣，1.0 代表完全分開。

The threshold τ is shared with unit 06. Change m in unit 04 and the whole pipeline (cells → semantics → scores → AUC) is recomputed.門檻 τ 和第 06 單元共用。改第 04 單元的 m，整條流程（格子 → 語意 → 分數 → AUC）都會重算。
