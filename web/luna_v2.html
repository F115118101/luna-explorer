01

What an LLM does: predict one token at a timeLLM 在做什麼：一次預測一個 token

Llama-2 is a decoder-only, autoregressive model: read the text so far, give probabilities for the next token, pick one, append it, repeatLlama-2 是 decoder-only 的自迴歸模型：讀前文，給下一個 token 的機率，挑一個接上去，再重複

A language model does exactly one thing: given the text so far, it outputs a probability distribution over the next token. Writing a sentence is that step repeated: pick a token, append it to the input, ask again. So the probability of a whole sentence splits into a product of per-step probabilities — the autoregressive factorization, which is also the training objective of the whole model (unit 07).一個語言模型只會做一件事：給它目前為止的文字，它輸出「下一個 token 是什麼」的機率分布。寫一整句話，就是把這件事重複做：挑出一個 token、接到輸入後面、再問一次。整句話的機率因此可以拆成每一步機率的連乘——這叫自迴歸分解，也是整個模型訓練的目標（第 07 單元）。

02

Tokenization: cutting text into tokens分詞：把文字切成 token

The model never sees letters, only integer ids of text pieces模型看不到字母，只看到「文字片段」的整數編號

The model's input is a list of integers. A tokenizer first cuts the text into pieces (tokens); each piece has an id in the vocabulary. Today's standard is subword cutting: common words stay whole, rare or long words are split into common pieces, and in the worst case into single bytes, so any text can be encoded.模型的輸入是一串整數。分詞器先把文字切成片段（token），每個片段在詞彙表裡有一個編號。現在的主流是子詞（subword）切法：常見的詞整個保留，罕見或很長的詞拆成常見的片段，必要時退回單一位元組，所以任何文字都切得出來。

The most common way to learn the cuts is BPE (Byte-Pair Encoding): start from single characters, count which two adjacent pieces occur together most often in the corpus, merge them into a new piece in the vocabulary, and repeat until the vocabulary reaches a preset size. At inference nothing is counted any more; the learned merges are just applied in order.最常見的學法是 BPE（Byte-Pair Encoding）：從單一字元開始，數一數語料裡哪兩個相鄰片段最常一起出現，把它們合併成一個新片段加進詞彙表，重複到詞彙表到達預定大小為止。推論時不再計數，只照學到的合併順序依序套用。

Llama-2 uses BPE as implemented in SentencePiece, which treats the space as an ordinary symbol written ▁: “▁is” means “is with a space before it”. The toy corpus below uses the same notation.Llama-2 用 SentencePiece 實作的 BPE：它把空白當成一般符號，寫成 ▁，所以「▁is」代表「前面有空白的 is」。下面的玩具語料就用這個寫法。

03

Embeddings: id → vector, and how they are learned嵌入：編號 → 向量，以及它是怎麼學出來的

The embedding table is just a big matrix; its numbers are trained together with the whole model, by predicting the next token嵌入表只是一個大矩陣；它的數字是跟整個模型一起，用「預測下一個 token」訓練出來的

An id means nothing by itself: token 500 and token 501 are not similar. The embedding table E is a “vocabulary × dimension” matrix with one row per token; looking a token up means taking row xt, which is the same as multiplying a one-hot vector by E.編號本身沒有意思：第 500 號和第 501 號不代表相近。嵌入表 E 是一個「詞彙數 × 維度」的矩陣，每一列是一個 token 的向量；查表就是取出第 xt 列。數學上等於拿 one-hot 向量去乘 E。

How embeddings are trained (the usual way in LLMs)嵌入是怎麼訓練的（LLM 最常見的做法）

In LLMs such as Llama and GPT the embedding table is not trained separately first. It is simply the first layer of parameters and is trained together with everything else, with one objective: predict the next token, minimize cross-entropy. E starts as random numbers; for each “current token → next token” pair the model computes a prediction, the error flows back through backpropagation, and in the end only the rows actually used in that step get updated.在 Llama、GPT 這類 LLM 裡，嵌入表不是另外訓練好再拿來用，而是模型的第一層參數，和所有其他參數一起，用同一個目標訓練：預測下一個 token，最小化交叉熵。一開始 E 是隨機數字；每看到一對「目前 token → 下一個 token」，模型算出預測機率，誤差沿著反向傳播一路傳回來，最後只更新這一步實際用到的那幾列。

Why do similar words end up close together? If two words are usually followed by the same things, they receive nearly the same gradients and get pushed in the same direction. The tiny model below is that process shrunk to the minimum: 11 words, 2-dimensional embeddings, and the next word predicted from the current word only (a one-layer language model without attention). Press “train” and watch the points move.為什麼意思相近的詞會靠在一起？因為兩個詞如果後面常接一樣的東西，它們收到的梯度就很像，會被往同一個方向推。下面這個小模型就是把這個過程縮到最小：11 個詞、2 維嵌入、只用「目前這個詞」預測下一個詞（等於一個沒有注意力的單層語言模型）。按「訓練」看點怎麼移動。

Another well-known method is word2vec (skip-gram with negative sampling): train a stand-alone word-vector table by letting a word predict the words around it. Same idea (learn from context), but as a separate step; modern LLMs do not need it — their embeddings are learned during pre-training.另一個常聽到的方法是 word2vec（skip-gram + 負取樣）：單獨訓練一張詞向量表，讓一個詞預測它周圍的詞。原理相同（「看上下文」），但它是獨立的一步；現在的 LLM 不需要它，嵌入直接在預訓練裡學出來。

04

Position: rotary position embedding (RoPE)位置：RoPE 旋轉位置編碼

Attention alone cannot tell word order, so position has to go into the vectors; Llama puts it in by rotating them注意力本身分不出先後，所以要把「第幾個」放進向量裡；Llama 用旋轉的方式放

Attention only compares how similar vectors are (unit 05): shuffle the words and the result is identical, so the model needs position information. The original Transformer and GPT-2 add a position vector to the embedding. Llama uses RoPE instead: the embedding is left alone, and inside attention the query q and key k are split into pairs of dimensions, each pair rotated by an angle that depends on the position.注意力只比較向量之間像不像（第 05 單元），把句子的字打亂順序，結果完全一樣。所以模型需要位置資訊。原始 Transformer 和 GPT-2 是把一個位置向量加到嵌入上；Llama 用的是 RoPE（Rotary Position Embedding）：不動嵌入，而是在注意力裡，把查詢向量 q 和鍵向量 k 每兩個維度一組，依位置旋轉一個角度。

Why rotate? q at position m is turned by mθ and k at position n by nθ, so their dot product depends only on the relative distance n − m. Try “both +1”: both arrows turn, the dot product does not change. Different pairs turn at different speeds θi: early pairs spin fast (they resolve short distances), late pairs turn very slowly (long distances).旋轉的好處：位置 m 的 q 轉了 mθ、位置 n 的 k 轉了 nθ，兩者的內積只取決於相對距離 n − m。試試「兩個一起 +1」：兩個向量都轉了，內積卻不變。不同的維度組用不同的轉速 θi：前面的組轉得快（分辨近距離），後面的組轉得很慢（分辨遠距離）。

05

Self-attention: every token looks back at the text before it自注意力：每個 token 回頭看前文

Score → softmax into weights → mix the earlier tokens' information by those weights; a causal mask hides the future打分 → softmax 成權重 → 依權重混合前面 token 的資訊；因果遮罩讓它看不到未來

From its own vector, every token computes three vectors: a query q (what am I looking for), a key k (what do I have) and a value v (what do I pass on). Token t scores every token by the dot product of its q with their k, divides by √dk to keep the numbers small, turns the scores into weights that sum to 1 with softmax, and adds up everyone's v with those weights.每個 token 由自己的向量算出三個向量：查詢 q（我想找什麼）、鍵 k（我有什麼）、值 v（我要提供什麼）。token t 拿自己的 q 跟每個 token 的 k 做內積當分數，除以 √dk 免得數字太大，經過 softmax 變成加總為 1 的權重，再用權重把大家的 v 加起來。

A decoder-only model adds a causal mask: a token may look only at itself and earlier tokens (masked scores are set to −∞, so their weight after softmax is exactly 0). This is the only place where tokens exchange information, which is why the hidden state of “er” contains information about “dens” and “Water vapor” — the states LUNA reads carry the context.decoder-only 模型還有因果遮罩：token 只能看自己和前面的 token（遮住的位置分數設成 −∞，softmax 後權重剛好是 0）。這是 token 之間唯一交換資訊的地方，所以「er」的隱藏狀態裡才會有「dens」、「Water vapor」的資訊——LUNA 讀到的狀態因此帶著前文。

06

Decoder block: normalize, compute, add back解碼器區塊：正規化、計算、加回去

Each block has two sub-layers (attention, feed-forward), and both only add a little to the token's vector每個區塊兩個子層（注意力、前饋層），都只是在 token 的向量上「加一點東西」

A block has two sub-layers and each does three things: normalize, compute, add the result back to the vector. That last step is the residual connection: every token has one vector flowing from the bottom to the top (the residual stream), and each sub-layer only adds a small change Δ to it. The output of block l, h(l), is the “hidden state” LUNA can read.一個區塊有兩個子層，每個都做三件事：先正規化、再計算、最後加回原本的向量。最後這個「加回去」叫殘差連接：每個 token 有一條向量從底層一路往上流（殘差流），每個子層只往上面加一點修改量 Δ。第 l 個區塊的輸出 h(l) 就是 LUNA 能讀的「隱藏狀態」。

  • RMSNorm: divide the vector by its root mean square so its size stays stable, then multiply by a learned gain g. It drops the “subtract the mean” step of GPT-2's LayerNorm.RMSNorm：把向量除以它的均方根，讓長度穩定，再乘一組學出來的增益 g。比 GPT-2 的 LayerNorm 少了「減平均」那一步。
  • Attention sub-layer: unit 05, the only place that reads other tokens.注意力子層：第 05 單元，唯一會讀其他 token 的地方。
  • Feed-forward (SwiGLU): one token at a time. Widen 4,096 dimensions to 11,008, let one branch pass through SiLU as a “gate” that multiplies the other branch, then shrink back to 4,096.前饋層（SwiGLU）：一次只處理一個 token。把 4,096 維放大到 11,008 維，一路經過 SiLU 當作「閘門」去乘另一路，再縮回 4,096 維。

PCA: 4,096 dimensions down to 3PCA：4,096 維壓到 3 維 LUNA 2 · reduceLUNA 2 · 降維

Find the directions in which the data varies most, and keep only the coordinates along those找出資料變化最大的幾個方向，只保留在這幾個方向上的座標

4,096 dimensions are far too many to cut into cells: 5 cells per dimension would give 54096 cells. LUNA first compresses each vector with principal component analysis (PCA): find the directions in which the data varies most, and keep only each point's coordinates along the first k of them. Our setting keeps k = 3.4,096 維太大，沒辦法直接切格子：每維切 5 格就有 54096 格。LUNA 先用主成分分析（PCA）壓縮每個向量：找出資料變化最大的幾個方向，每個點只保留它在前 k 個方向上的座標。我們的設定保留 k = 3。

One formula for any d → k一條式子：任意 d 維降到任意 k 維

Write the centered training vectors as rows of a matrix (N rows, d columns) and let C be their d × d covariance matrix. Reducing to k dimensions means choosing k orthonormal directions, i.e. a d × k matrix W with W⊤W = Ik, and keeping each vector's coordinates z = W⊤(h − μ). PCA picks the W whose coordinates keep the most variance:把中心化後的訓練向量排成一個矩陣（N 列、d 欄），C 是它們的 d × d 共變異數矩陣。降到 k 維，就是選 k 個互相垂直的單位方向，也就是一個 d × k 的矩陣 W，滿足 W⊤W = Ik，每個向量只留下座標 z = W⊤(h − μ)。PCA 挑的是讓這些座標保留最多變異的那個 W：

Wk = argmaxW ∈ ℝd×k, WᵀW = Ik tr(Wᵀ C W)  ⇒  columns of Wk = the k eigenvectors of C with the largest eigenvaluesWk 的各欄 = C 最大的 k 個特徵值對應的特徵向量

This single formula covers every case: d = 4,096 and k = 3 is our LUNA setting, d = 12 is the toy data below, and the textbook 2-D picture is just d = 2, k = 1. Two facts make it easy to read: the variance kept is λ1 + … + λk, and the average squared error of reconstructing h from z is exactly the rest, λk+1 + … + λd. So “keep the most variance” and “lose the least information” are the same goal. In the figure, change d and k and compare the reconstruction error measured on the data with the sum of the discarded eigenvalues.所有情況都是這一條：d = 4,096、k = 3 就是我們的 LUNA 設定，d = 12 是下面的玩具資料，課本常畫的二維圖只是 d = 2、k = 1 的特例。兩件事讓它很好讀：保留的變異量是 λ1 + … + λk；從 z 重建回 h 的平均平方誤差剛好是剩下的 λk+1 + … + λd。所以「保留最多變異」和「丟掉最少資訊」是同一件事。在下圖改 d 和 k，比較在資料上實際量到的重建誤差和被丟掉的特徵值總和。

Why the answer is the top-k eigenvectors為什麼答案是前 k 個特徵向量

Write C = VΛV⊤ with eigenvalues λ1 ≥ … ≥ λd. For any orthonormal W, tr(W⊤CW) is a weighted sum of the λi whose weights lie between 0 and 1 and add up to k, so it can never exceed λ1 + … + λk — and the first k eigenvectors reach exactly that. (Setting the derivative of the Lagrangian to zero gives the same condition CW = WΛk.) The solution is unique up to rotations within the kept subspace, and for k = 1 it reduces to the familiar “the best single axis is the top eigenvector”.把 C 寫成 VΛV⊤，特徵值 λ1 ≥ … ≥ λd。對任何正交的 W，tr(W⊤CW) 都是 λi 的加權和，每個權重介於 0 和 1 之間、加起來等於 k，所以它不可能超過 λ1 + … + λk——而前 k 個特徵向量剛好達到這個值。（對拉格朗日函數求導令其為 0，得到的也是同一個條件 CW = WΛk。）在保留的子空間內旋轉不影響結果；k = 1 時就是大家熟悉的「最好的那一條軸是最大特徵向量」。

The recipe LUNA runsLUNA 實際跑的步驟

  1. Center: subtract the mean μ of all training tokens.中心化：減掉訓練集所有 token 的平均 μ。
  2. Covariance: C = (1/(N−1)) Σ (h − μ)(h − μ)⊤, a 4,096 × 4,096 matrix.共變異數：C = (1/(N−1)) Σ (h − μ)(h − μ)⊤，一個 4,096 × 4,096 的矩陣。
  3. Eigendecomposition: sort the eigenvectors by eigenvalue (scikit-learn does this through an SVD of the centered data, which gives the same directions).特徵分解：依特徵值由大到小排特徵向量（scikit-learn 實際上是對中心化後的資料做 SVD，得到的方向相同）。
  4. Project: z = Wk⊤(h − μ) keeps k numbers per token. Steps 1–3 use the training set only; test tokens reuse the same μ and Wk.投影：z = Wk⊤(h − μ)，每個 token 只剩 k 個數字。第 1–3 步只用訓練集；測試 token 沿用同一組 μ 和 Wk。

Score every test answer, sweep every threshold, draw the ROC curve; the area under it = the chance a random true answer scores above a random hallucination對所有測試回答算分數，掃過每一個門檻，畫出 ROC 曲線；曲線下面積 = 隨機一個真實回答分數高於隨機一個幻覺回答的機率

One threshold gives one result. Sweep the threshold from 0 to 1 and compute two rates at each: TPR (share of hallucinations caught) and FPR (share of true answers wrongly flagged); joined up they form the ROC curve. The area under it, AUC, does not depend on the threshold: 0.5 is a coin flip, 1.0 means perfectly separated.單一門檻只能給一組結果。把門檻從 0 掃到 1，每個門檻都算兩個比例：TPR（幻覺被抓到的比例）與 FPR（真實回答被誤判的比例），連起來就是 ROC 曲線。曲線下的面積 AUC 不受門檻影響：0.5 等於擲硬幣，1.0 代表完全分開。

The threshold τ is shared with unit 12; change m or N in unit 10 and the whole pipeline (cells → semantics → scores → AUC) is recomputed.門檻 τ 和第 12 單元共用；改第 10 單元的 m 或 N，整條流水線（格子 → 語意 → 分數 → AUC）都會重算。
