Tokenization — cutting text into tokens分詞——把文字切成 token

The model never sees letters, only integer ids of text pieces模型從來看不到字母，只看到文字片段的整數編號

Before anything else, a tokenizer cuts the text into pieces called tokens and gives each piece an integer id. Today's standard is subword-level cutting: keep common words whole, and split rare or long words into reusable pieces such as roots, prefixes and suffixes — so unfriendly might become un · friend · ly. This keeps the vocabulary small and finite while still handling words never seen in training, by falling back to smaller known pieces (down to single bytes if needed).在一切開始之前，分詞器先把文字切成一段一段叫 token 的片段，每段給一個整數編號。現在的主流是子詞級切法：常見的詞保持完整，罕見或很長的詞拆成可重複使用的片段，例如字根、字首、字尾——所以 unfriendly 可能變成 un · friend · ly。這讓詞彙表維持小而固定的大小，又能處理訓練時沒看過的詞：往下退回更小、已知的片段（必要時退到單一位元組）。

Three common subword algorithms: BPE (start from single characters or bytes, repeatedly merge the most frequent adjacent pair; GPT-2 uses a byte-level version), WordPiece (BERT; picks merges by a language-model score and marks continuations with ##), and SentencePiece (Llama 1/2; treats the space as an ordinary symbol, so it needs no language-specific preprocessing and suits Chinese and Japanese).三種常見的子詞演算法：BPE（從單一字元或位元組開始，反覆合併最常相鄰的一對；GPT-2 用位元組版）、WordPiece（BERT；用語言模型分數決定合併，非字首的片段加 ##）、SentencePiece（Llama 1/2；把空白當成一般符號，不需語言專屬的前處理，對中文、日文友善）。

When does BPE stop merging? Training fixes a target vocabulary size in advance (GPT-2: 50,257); merging repeats, largest pair first, until the vocabulary reaches that size — not until the text is “fully” merged. A small or repetitive corpus can also run out of pairs that occur more than once before reaching that size, in which case merging stops early (this is what the toy corpus below does, since it is tiny). At inference the tokenizer no longer counts anything — it just applies the merges it learned, in the order it learned them.BPE 什麼時候停止合併？訓練前會先定好目標詞彙表大小（GPT-2 是 50,257）；合併一直挑最高次數的那一對繼續做，直到詞彙表到達這個大小為止——不是切到「切不動」才停。語料如果很小或重複性高，也可能在到達目標大小之前，就找不到出現兩次以上的組合，於是提早停止（下面的玩具語料因為太小，就是這種情況）。推論時分詞器不再計數，只是照著訓練時學到的合併順序，依序套用。

In plain words白話說明

The model cannot read letters, only numbers. A tokenizer is like a dictionary that cuts a sentence into small pieces and looks up each piece's number. BPE is how that dictionary is built: start with single letters, find the two pieces that most often sit next to each other (say e + r), glue them into one new piece and add it to the dictionary, and repeat until the dictionary is big enough. So common words end up as one piece and rare words are split into several.模型看不懂字母，只看得懂編號。分詞器就像一本字典：把句子剪成一小塊一小塊，再查出每一塊的編號。BPE 是編這本字典的方法：先把每個字母當成一塊，找出最常黏在一起出現的兩塊（例如 e + r），把它們黏成一塊新的放進字典，一直重複到字典夠大為止。所以常見的詞會變成一整塊，罕見的詞會被拆成好幾塊。

Self-attention自注意力

Each token decides how much to look at every other token每個 token 決定要多關注其他每一個 token

For every token, attention scores how relevant each other token is, turns the scores into weights with softmax, and mixes the other tokens' vectors with those weights. In A baby sat on the chair, sat looks at baby and chair more than at the. A decoder-only model adds a causal mask: a token may only look at itself and earlier tokens.對每個 token，注意力先為其他每個 token 的相關程度打分，再用 softmax 把分數變成權重，最後用權重混合其他 token 的向量。在 A baby sat on the chair 裡，sat 對 baby 和 chair 的關注高於 the。decoder-only 模型多一個因果遮罩：token 只能看自己和之前的 token。

In plain words白話說明

When the model reads a word it asks: “which earlier words matter to me?” It gives each earlier word a relevance score, turns the scores into percentages that add up to 100%, and mixes those words' information into its own vector in those proportions — like working out who “it” refers to. The causal mask is the rule that you may only look at what has already been written, never at words that come later. τ works like a contrast knob: small τ = stare at one word, large τ = look at all of them equally.模型讀到一個字時會問：「前面哪些字跟我有關？」它幫前面每個字打一個相關分數，換算成加起來 100% 的比例，再照這個比例把那些字的資訊混進自己的向量——就像讀到「it」時回頭找它指的是誰。因果遮罩是一條規則：只能看已經寫出來的字，不能偷看後面還沒寫的。τ 像對比度旋鈕：τ 小＝只盯著一個字，τ 大＝每個字都平均看一點。

Decoder block and the residual stream解碼器區塊與殘差流（residual stream）

Each block only adds to a token's vector — and that vector is what LUNA reads每個區塊只是往 token 的向量上「加東西」——而這個向量就是 LUNA 讀的東西

A decoder block has two sub-layers, and each one does the same three things: normalize, compute, add back. For token t in block l (GPT-2 puts the normalization first):一個解碼器區塊有兩個子層，每個子層都做同樣三件事：正規化、計算、加回去。第 l 個區塊裡的第 t 個 token（GPT-2 是先正規化）：

at = ht(l−1) + Attn( LN(h1(l−1)), …, LN(ht(l−1)) )t
ht(l) = at + MLP( LN(at) )

The “+” is the residual connection. What is added back is the same token's vector from the block below — not the previous token's. So every token has one vector that flows up through all the blocks (12 in GPT-2 small, 768 numbers; 32 in Llama-7b, 4,096 numbers), and each sub-layer only adds a little to it. This running vector is called the residual stream. Attention is the only place where tokens exchange information (it reads earlier tokens, see self-attention); the MLP works on one token at a time. The residual runs upwards through the layers, while an RNN's memory runs sideways through time (RNN vs Transformer). After the last block, one more normalization (GPT-2's ln_f) is applied before the output layer.「+」就是殘差連接。加回去的是同一個 token 在下一層的向量，不是前一個 token 的。所以每個 token 都有一個向量，一路往上流過所有區塊（GPT-2 small 有 12 個區塊、768 個數字；Llama-7b 有 32 個、4,096 個數字），每個子層只往上面加一點東西。這個一路累加的向量叫殘差流（residual stream）。token 之間只有在注意力這一步交換資訊（它讀前面的 token，見自注意力）；MLP 一次只處理一個 token。殘差是沿著層往上走，RNN 的記憶則是沿著時間往旁邊走（見 RNN 與 Transformer）。最後一個區塊之後，還會再做一次正規化（GPT-2 的 ln_f），才進輸出層。

Link to LUNA. The “decoder block output” LUNA uses as its concrete state is the residual stream after block l — in Hugging Face, hidden_states[l] (hidden_states[0] is embedding + position). RNN vs Transformer — and why LUNA's state is an approximationRNN 與 Transformer——以及為什麼 LUNA 的狀態是近似

An RNN is a state machine by construction; a Transformer is not, so LUNA has to pick a state and assume it is MarkovRNN 本身就是狀態機；Transformer 不是，所以 LUNA 必須自己選一個狀態，並假設它符合馬可夫性質

RNN. A recurrent network reads one token at a time and updates a single memory vector: ht = f(ht−1, xt). Everything it has read must be squeezed into that fixed-size vector, and step t sees the past only through ht−1 — so it must run step by step, and information from early tokens fades as it passes through many updates. This is already “current state + input → next state”, which is why earlier model-based analyses (DeepStellar, RNNRepair and others) could cluster ht into abstract states and read off an automaton directly.RNN。循環神經網路一次讀一個 token，更新一個記憶向量：ht = f(ht−1, xt)。讀過的所有內容都要壓進這個固定大小的向量，第 t 步只能透過 ht−1 看到過去——所以只能一步一步算，早期 token 的資訊經過多次更新也容易被沖淡。這個結構本身就是「目前狀態 + 輸入 → 下一個狀態」，所以過去的模型化分析（DeepStellar、RNNRepair 等）可以直接把 ht 分群成抽象狀態，讀出一個自動機。

Transformer. There is no memory vector passed along. At every layer, token t uses self-attention to look directly at all earlier tokens 1 … t. What is actually carried from step to step during generation is the KV cache: the key and value vectors of every earlier token at every layer, which grows with the length of the text. No early token has to survive a chain of updates, and training can process all positions in parallel. Each block does add its result back onto the token's own vector (the residual connection), but that runs up through the layers, not along time — see Decoder block.Transformer。沒有往下傳的記憶向量。在每一層，第 t 個 token 都用自注意力直接看前面所有的 token 1 … t。生成時真正一步步帶著走的是 KV cache：前面每個 token 在每一層的 key 和 value 向量，會隨文字長度變大。早期的 token 不必撐過一連串更新，訓練時也能所有位置平行計算。每個區塊確實會把結果加回 token 自己的向量（殘差連接），但那是沿著層往上，不是沿著時間——見解碼器區塊。

What LUNA does. The full Transformer “state” (the KV cache) has no fixed size, so it cannot be clustered. LUNA instead takes one fixed-size vector per token — a decoder block's output for that token — as the concrete state, clusters it into an abstract state st, and fits a DTMC, which assumes the next state depends only on the current one. That is an approximation in two ways: (1) the model's next step actually reads every earlier token, not only token t's vector; (2) clustering merges different vectors into one state, so some of the history that vector did carry is thrown away. It works to the extent that attention has already mixed the relevant history into each token's vector and the clustering keeps those differences apart — the second figure shows both cases.LUNA 怎麼做。Transformer 完整的「狀態」（KV cache）大小不固定，沒辦法分群。所以 LUNA 改用每個 token 一個固定大小的向量——該 token 在 decoder block 的輸出——當具體狀態，分群成抽象狀態 st，再建一條DTMC，假設下一個狀態只取決於目前狀態。這在兩方面是近似：（1）模型的下一步其實會讀前面所有 token，不只第 t 個 token 的向量；（2）分群會把不同的向量併成同一個狀態，向量裡原本帶著的部分歷史就被丟掉了。它能用的前提是：注意力已經把相關的歷史混進每個 token 的向量裡，而且分群沒有把這些差異併掉——第二張圖示範這兩種情況。

Hidden Markov model and Baum-Welch隱馬可夫模型與 Baum-Welch

When the states you care about are hidden and you only see their symptoms真正的狀態看不到，只看得到它們的外在表現

Sometimes the states that really drive a sequence are not directly visible — you only see a symbol each one tends to produce. A hidden Markov model (HMM) models exactly that: a hidden chain of states, and a separate visible sequence of symbols it emits. It has three parts:有時候真正在驅動一串資料的狀態不是直接看得到的，你只看得到每個狀態傾向產生的符號。隱馬可夫模型（HMM）就是在描述這件事：一條看不見的隱藏狀態鏈，加上它發射出來、看得到的一串符號。它由三部分組成：

  • Hidden states that switch according to transition probabilities.隱藏狀態：依轉移機率互相切換。
  • Emission probabilities: each hidden state produces each visible symbol with its own probability.發射機率：每個隱藏狀態各自以一組機率產生看得到的符號。
  • Initial probabilities: how likely each hidden state is at the start.初始機率：一開始各隱藏狀態的可能性。

Once you have these numbers you can do two things with a new sequence of symbols. The forward algorithm tells you how likely the sequence is under the model. The Viterbi algorithm guesses the most likely hidden-state sequence behind it.有了這些數字，面對一串新符號可以做兩件事：前向算法算出這串符號在模型下有多可能；Viterbi 猜出背後最可能的隱藏狀態序列。

But where do the numbers come from? Usually you only have the visible sequences. That is a chicken-and-egg problem: with the hidden states you could just count, and with the numbers you could guess the hidden states. Baum-Welch (an EM algorithm) solves it by alternating: guess the hidden states “softly” with the current numbers (a 70% / 30% guess, not a hard choice), recount using those guesses, and repeat. Each round makes the training sequences at least as likely as before.那這些數字從哪來？通常你手上只有看得到的序列。這是雞生蛋、蛋生雞：知道隱藏狀態就能直接數出機率，知道機率又能猜出隱藏狀態。Baum-Welch（一種 EM 演算法）用輪流修正來解：先用目前的數字「軟性」猜隱藏狀態（例如 70% 是這個、30% 是那個，不硬選），再用這些猜測重新計數，然後重複。每一輪都會讓訓練序列的似然上升或不變。

Adversarial attacks對抗攻擊

Small edits a person barely notices, chosen on purpose to flip the model's answer人幾乎察覺不到的小改動，卻是刻意挑來讓模型答錯的

Neural networks are highly non-linear, so a tiny change to the input can move the output a lot. An adversarial attack exploits this on purpose: it is an optimisation problem, “find the smallest edit that changes the prediction”. For images the edit is a continuous nudge to pixel values. Text is discrete, so attacks swap characters, words or whole sentences instead. The paper uses AdvGLUE++ from the DecodingTrust benchmark, which contains five word-level attacks. LUNA does not try to make the LLM robust (adversarial training and certification are too costly for LLMs). It only tries to detect the attack, so the system can refuse or take some other action.神經網路高度非線性，輸入一點點改動就可能讓輸出差很多。對抗攻擊就是刻意利用這一點，它是一個最佳化問題：「找出能讓預測改變的最小改動」。影像的改動是對像素值做連續的微調；文字是離散的，所以攻擊改的是字元、單字或整句。論文用的是 DecodingTrust 基準裡的 AdvGLUE++，包含五種詞級攻擊。LUNA 不嘗試讓 LLM 變得強健（對抗訓練與強健性認證對 LLM 來說太昂貴），只負責偵測攻擊，偵測到就可以拒絕回答或採取其他動作。

Hallucination幻覺

Fluent, confident, and wrong — the model makes up content that is not true通順、自信，但是錯的——模型編出不符事實的內容

A hallucination is generated content that is unfaithful to the input or not factual. The paper follows the usual split into two kinds. An intrinsic hallucination contradicts the source or known reality: asked whether it has human qualities, a model answers “yes”. An extrinsic hallucination cannot be verified from anything given: asked where the NASDAQ will go tomorrow, it answers “up”. Unlike OOD inputs or adversarial edits, nothing about the input looks wrong. The problem is in the output, so spotting it normally needs a person or an external judge who knows the facts. Fixes such as cleaning the training data or changing the model are very costly at LLM scale, which is why the paper tries detection instead.幻覺是指生成的內容不忠於輸入、或不符合事實。論文沿用常見的兩種分類。內在幻覺和來源或已知事實矛盾：問模型「你有人類的特質嗎？」它答「有」。外在幻覺則是無法從任何已給的資訊驗證：問它明天 NASDAQ 會怎麼走，它答「會漲」。和分布外輸入或對抗改動不同，這裡的輸入完全正常，問題出在輸出，所以通常要有懂事實的人或外部評審才看得出來。清理訓練資料、修改模型這類修正方法在 LLM 的規模下太昂貴，所以論文改走偵測這條路。

KL divergence measures how far a distribution Q is from a reference P. It is 0 only when they are identical and it is not symmetric.
